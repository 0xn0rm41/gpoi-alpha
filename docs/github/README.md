# GitHub guide

Practical GitHub material for Hub Studenti contributors.

| File | Content |
|---|---|
| [CHEATSHEET.md](CHEATSHEET.md) | git, branching, PRs, issues/labels, Actions, branch protection, Dependabot, security, releases, CODEOWNERS, DCO, gh CLI |
| [templates/ISSUE_BUG.md](templates/ISSUE_BUG.md) | Bug report template |
| [templates/ISSUE_FEATURE.md](templates/ISSUE_FEATURE.md) | Feature request template |
| [templates/PULL_REQUEST.md](templates/PULL_REQUEST.md) | Pull request template |

To activate templates in the repository, copy them to `.github/ISSUE_TEMPLATE/` (issues, optionally as YAML forms) and `.github/pull_request_template.md`. This folder only stores the drafts; nothing here changes the repository settings.
