# RACI

R = Responsible (does the work), A = Accountable (one person, final say), C = Consulted, I = Informed. Roles can be held by the same person in a small team; keep exactly one A per row. External roles are not paid in the model unless stated.

Roles: **PL** Project Lead, **TL** Tech Lead, **CL** Community Lead (schools, moderation, feedback), **FL** Finance and Legal Lead, **CO** Contributors, **SC** Pilot school contact, **AC** Commercialista / lawyer (external).
